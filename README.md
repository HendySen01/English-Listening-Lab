# 英语学习实验室

本地网页应用：每天学习一组新词、短例句、必要的词根、可播放的听力和三道题，并用 FSRS 安排复习。

项目目录：`D:\Projects\English-Listening-Lab`。数据库也在这个目录的 `data` 文件夹。

## 启动

在 PowerShell 中：

```powershell
cd D:\Projects\English-Listening-Lab
powershell -ExecutionPolicy Bypass -File .\scripts\dev.ps1
```

浏览器打开 `http://127.0.0.1:5173`。

第一次没有配置 API 时，会直接打开一节离线示范课，不会假装已经调用了 AI。

## 配置 API

复制 `apps/server/.env.example` 的内容本来就在 `apps/server/.env`。只在后端填写：

- `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`
- 可选：`TTS_API_KEY`、`TTS_BASE_URL`、`TTS_MODEL`、`TTS_VOICE`

前端拿不到密钥。没有 TTS 时使用浏览器语音，页面会说明不同浏览器的暂停和音色可能不一致。

## 数据

SQLite 文件：`D:\Projects\English-Listening-Lab\data\lab.db`

初始化：

```powershell
npm run db:push -w @lab/server
```

## 这次验证过的

- 项目在 `D:\Projects\English-Listening-Lab`，数据库在该目录的 `data\lab.db`。
- Windows 上前后端可以启动：页面 `http://127.0.0.1:5173`，接口 `http://127.0.0.1:8787`。
- 第一次进入会生成 6 个词的离线示范课。再请求一次，课程 id 不变，AI 调用次数仍是 0。
- 把设置改成 8 个、B1 后，下一天的课是 8 个 B1 词；当天已经生成的 6 个词不变。
- 例句都包含目标词，长度不超过 14 个词。词根不超过 2 个，并且词根确实出现在单词里。
- 6 个词、没有到期复习时，预计时间是 60 分钟；20 个词会更长。
- 提交测验前接口不返回答案；提交后返回对错、中文解析和英文解析。
- 复习评分后，下次时间晚于当前时间。
- 页面上点“读单词”会调用浏览器英语语音；“慢一点”的语速是 0.8。自动化环境只能确认调用了语音接口，不能代替你的扬声器。
- 把 AI 地址指到无法连接的端口时，提示“连不上语言模型接口”，不会保存半成品。
- 窄屏下导航会换行，课程内容仍在一列里。

没有配置真实的 LLM 或 TTS 密钥，所以没有验证付费接口的实际生成和音频文件。价格没有估算。

## 限制

- 60 分钟和 6 个新词是起始安排，不是研究结论。
- 离线听力是慢速短句。学习天数只影响离线短文长度，不会在第四周自动变成四级真题。
- AI 不显示未经核对的音标。离线音标是人工整理的通用美式教学音标。
- 浏览器语音不是自然 TTS。没有配置语音接口时，不会伪造音频文件。
- 没有发音评分接口，跟读只由你自己标记。
- 数量建议来自最近答题和复习记录，样本不足时不判断水平。
- token 只在供应商返回时记录。程序不估算价格。
- 用本仓库脚本时，npm 缓存写到项目里的 `.cache`。Windows 自己的临时文件仍可能出现在 C 盘。
