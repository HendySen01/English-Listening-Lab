# 学习体验独立分支验收

此分支仅包含待验收的改版，不能视为已发布。

- GitHub Actions 在 redesign/learning-experience 的 push 上运行锁定依赖安装、前端构建、非阻断 TypeScript 诊断及 Chromium / WebKit 浏览器测试。
- 浏览器使用正式 /lesson 路由和固定模拟 API；测试中拦截所有非本机网络请求。不会读取生产数据库、使用密钥、调用真实 AI/TTS 或执行部署。
- 检查复习答案默认隐藏、翻译点击切换、实际间隔标签、失败保留卡片、同请求号重试、自动下一词以及词根页复用缓存。
- 截图与日志上传至 Actions artifact，内容只包含测试数据。最新 WebKit 不等同 iOS 15.6 Safari 真机。
- 当前改版其他待办：0.7/1/1.3 语速、英文听力反馈、逐句译文、完整学习路径；不要将测试范围扩大解释为这些功能已实现。
