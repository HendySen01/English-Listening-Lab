# 开源方案

检索时间：2026-11-22。结果来自公开网页，不是凭星数选用。

## 采用

- [open-spaced-repetition/ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs)，MIT。安装 `ts-fsrs@5.3.2`。Node 24 可用。只使用它的复习排程，不自己发明记忆算法。

## 参考，不整库搬入

- [TICKurt/english-dictionary-web](https://github.com/TICKurt/english-dictionary-web)，MIT。Vue 3 单词站，SM-2，依赖 Supabase，没有本项目的四轮听力和每日 AI 课。
- [ilovend/wordeasy](https://github.com/ilovend/wordeasy)，MIT。拼写游戏，FastAPI，复习间隔是固定天数。
- [amluckydave/shiyu](https://github.com/amluckydave/shiyu)，MIT。Tauri 阅读器，技术栈不同。
- [ChihoYiu/CetVocab](https://github.com/ChihoYiu/CetVocab)，MIT。Android 离线背词，不能作为这个网页的基础。
- [CanFlyhang/CET-MASTER](https://github.com/CanFlyhang/CET-MASTER)，MIT。静态页面和简易遗忘曲线，没有听力课和 API 校验。

## 不采用

- [zyronon/TypeWords](https://github.com/zyronon/TypeWords)，GPL-3.0。打字产品，许可证不适合直接并入，词库来源也需要另审。
- [zhanfoguang/mamio-ielts](https://github.com/zhanfoguang/mamio-ielts)，页面写 MIT，但是雅思站，维护记录少，不作为基础。
- LeiBox 当时返回的是上传动画、品牌卡片和音乐播放装饰，没有适合学习流程的组件，所以没有接入。

没有找到可以同时覆盖每日短课、听力四轮、测验校验和 FSRS，并且技术栈可直接运行的成熟项目，所以课程流程是按这些库的可复用部分自己实现的。
