## 目标

English Listening Lab 是给本人和朋友使用的英语学习实验室：新词、词根、语境阅读、听力、跟读、回忆和 FSRS 复习。每个账号从空学习数据开始，互不看见对方的课程、词汇、复习和统计。

## 当前架构

- 正式站：Vercel Production，`https://english-listening-lab.vercel.app`。
- 数据库：Neon Production，`neondb`，独立端点；业务 schema `lab_phase_h`，认证 schema `lab_phase_h_auth`。不使用 `public`，不使用 Preview 的 development 连接。
- 本地：`apps/web`（Vue 3 + Vite）、`apps/server`（Express 5 + Prisma 6.19.3）。本机 `8787` 仍可走 SQLite `data/lab.db`。
- 身份：Better Auth 邮箱密码、数据库会话、邀请码注册、注册/登录限流、每账号一个 Learner。
- AI：DeepSeek 已在 Production 做最小探测。额度每人每天 200 次、全站每天 1500 次，按 Asia/Shanghai 学习日；只计实际模型请求。
