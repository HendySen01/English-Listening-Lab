# 计划书

核对日期：2026-11-23。本地多用户学习流程已在浏览器验收。Vercel Preview 仍未部署。

## 已验证

- 受保护前端 `http://127.0.0.1:5174` 只代理 `127.0.0.1:8797`。未登录访问课程返回 401，没有退回 8787。
- 两个隔离账号可以登录、退出；错误密码停在登录页并提示「邮箱或密码不正确」。刷新后会话仍在。
- 首页、语境阅读、我的课程、历史课程、词汇库、听力阶段、正式复习、提前练习、统计、浅色和深色都按当前账号显示。
- 正式 FSRS 评分会改下一次时间；提前练习不改。两个账号的课程、词汇和复习时间互不可见。
- 课程生成、深度解析、例句和额度测试都走 Mock。未配置预算时，真实付费请求仍返回拒绝。
- 「继续学习」「查看课程详情」以及同类操作文字垂直居中。

## 已实现

- 多用户接口补齐现有页面要读的课程、词汇、复习和进度字段。

- `LAB_AI_MOCK=1` 只在本次隔离进程启用。默认仍拒绝付费模型。
