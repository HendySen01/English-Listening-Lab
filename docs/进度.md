## 启动 Preview 前要手动完成

1. 项目根目录选择仓库根，确认能读到根目录 `vercel.json`。Services 处于 Beta。
2. 只在 Preview 设置 `BETTER_AUTH_SECRET`、`NEON_DATABASE_URL`、`NEON_DIRECT_URL`。密钥新建，连接必须是 development 的 pooled 与 direct。
3. 不设置 `DEEPSEEK_API_KEY`，不设置 `AUTH_SIGNUP=open`，不把 schema 改成 public。
4. `BETTER_AUTH_URL` 留空，让运行时使用当前部署的 `https://VERCEL_URL`。不要把 Production 域名写进 Preview。
5. 部署命令需要另一次明确授权。本地 8787 继续使用 SQLite。
