# 学习台设计决定

UI UX Pro Max 的两次设计系统检索都跑过，结果没有直接采用。

第一次检索把产品判成儿童教育，给出黏土风和 Baloo 2 / Comic Neue。这和每天学习 60 分钟的成人工作台冲突，所以不用。

第二次检索给出液态玻璃和衬线时装字体。模糊和折射会降低长文可读性，也不用。

实际采用的是同一次检索里适用于本产品的规则：正文对比至少 4.5:1，焦点环至少 2px，悬停只改背景不把深色字留在深色底上，点击目标至少 44px，图标用 Lucide，尊重减少动效。主按钮在浅色和深色里都使用白字加深青底，悬停时只把底色加深。

英文单词用 Georgia 大字，中文界面用系统无衬线。首页不再使用四张相同统计卡，单词和学习倒计时分成主次两栏。
