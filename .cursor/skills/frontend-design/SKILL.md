# Frontend Design

Source read from https://github.com/anthropics/skills/tree/main/skills/frontend-design on 2026-11-22. Git clone of the repository failed to connect; this file is the raw SKILL.md saved locally so Cursor can read it. The license terms remain with the upstream LICENSE.txt.

Approach this as the design lead. Ground the design in the subject. For this project the subject is an adult daily English study desk, not a children's toy and not a fashion landing page.

The skill requires a two-pass plan: palette, type, layout, principles, then a critique against generic defaults. Cream-and-terracotta, acid-green-on-black, identical SaaS cards, and all-caps eyebrows were treated as defaults to avoid unless the brief asks for them.

Boldness belongs in one place. Here that place is the English word itself. Controls stay quiet, with visible hover, focus, and disabled states.
